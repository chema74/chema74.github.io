🔍 Para responsables de selección técnica

Este portfolio está diseñado para revisarse en menos de 5 minutos. Sin demos en la nube, sin promesas infladas. Solo código ejecutable localmente.

1️⃣ Revisión rápida (2 min)

Abre agentes-ia-pymes. Lee el README. Verifica los 135 tests que pasan en local.

2️⃣ Demo reproducible (5 min)

Ejecuta en tu terminal:
python scripts/ejecutar_demo_local.py
Genera informes y evidencias sin configurar nada.

3️⃣ Profundización (15 min)

Explora laboratorios especializados: RAG corporativo, gobernanza AI Act, privacidad. Documentación en castellano y límites claros.

💡 Nota: Todos los proyectos son local-first. No requieren API keys, cuentas cloud ni entornos complejos.
